# 人民币金额大写转换器

在线使用：<https://rmb.wwz.im/>

一个基于 Vite、React 和 TypeScript 的人民币金额大写转换工具。金额转换在浏览器本地完成，不需要登录，也不会上传输入金额。

## 转换规则

- 固定显示“圆、角、分”三个单位。
- 角、分为零时仍保留对应单位，不追加“整”字。
- 支持最多 16 位整数和最多 2 位小数。
- 支持复制结果和常用金额快捷填入。

## 本地开发

\`\`\`bash
npm install
npm run dev
\`\`\`

## 构建与检查

\`\`\`bash
npm run build
npm run lint
\`\`\`
